🔨 Making It Right — Recovering a Missed Mark

A miss isn’t always the end of the month. Where the value can still be recovered, you can make it right and earn partial credit back. Where the value is time-sensitive and permanently lost — documentation that had to be captured on site, an estimate that had to go out same-day, a no-call/no-show that left the team short — it can’t be made up. That’s the line: recoverable value can be earned back; lost value can’t.

✓ Can be made up → restores to Partial ($50)
✕ Can’t be made up

A successful makeup restores the metric to Partial ($50) — it credits the recovery while keeping a clean, first-time Met ($100) meaningful. The Van Reset is the one exception: a full Saturday of warehouse organization / equipment decontamination restores the full value ($100), reflecting the real extra effort. Makeups are confirmed by management.

How metrics earncount:  Building metrics (jobsite docs, EOD, water tags, breakfasts, drop-offs) start at $0zero and build up as you do them — an open dot means “in progress, still earningbuilding.”  Clean-record metrics (attendance, no reworks, van reset) start the month on track for the full amountscore and stay green as long as the record stays clean. This way nothing rewards an unwanted event, and the open dots early in the month simply mean the month is still young.
